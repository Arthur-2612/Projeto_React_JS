# React Lab

Uma aplicação educacional desenvolvida com React e Vite para explorar fundamentos do desenvolvimento front-end, com foco em componentes, props, listas, renderização condicional e Virtual DOM.

## 📌 Sobre o projeto

Este projeto foi construído como uma referência prática para estudar e demonstrar conceitos importantes do React, incluindo:

- JSX e sintaxe do React
- Componentização e reutilização
- Props e passagem de dados
- Estados com `useState`
- Efeitos com `useEffect`
- Renderização condicional
- Listas e chaves (`keys`)
- Scroll suave e navegação entre seções
- Virtual DOM e atualizações reativas

## ✨ Funcionalidades

- Navegação por seções com destaque visual
- Layout moderno e responsivo
- Barra de progresso de leitura
- Demonstração de conceitos em blocos de conteúdo
- Interface clara e didática para estudo

## 🚀 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/Arthur-2612/Projeto_React_JS.git
```

2. Acesse a pasta do projeto:

```bash
cd Projeto_React_JS
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Abra no navegador a URL mostrada no terminal, geralmente:

```bash
http://localhost:5173
```

## 🛠️ Scripts disponíveis

```bash
npm run dev     # inicia o ambiente de desenvolvimento
npm run build   # gera a build de produção
npm run preview # visualiza a build localmente

```
